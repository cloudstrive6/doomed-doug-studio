# Doomed Doug Publisher: Privacy Policy

Doomed Doug Publisher is a private tool used only by the owner of the Doomed Doug YouTube channel to upload its
own videos and read its own channel analytics through the YouTube API Services.

- It accesses only the owner's own YouTube channel, with the owner's explicit OAuth consent.
- It does not collect, store or share data about any other user.
- Channel analytics are stored privately by the owner to improve the channel's content.
- Access can be revoked at any time at https://myaccount.google.com/permissions.

This tool uses YouTube API Services. See the YouTube Terms of Service (https://www.youtube.com/t/terms) and the
Google Privacy Policy (https://policies.google.com/privacy).
